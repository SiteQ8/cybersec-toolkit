# CyberSec Toolkit\n\nA guided open-source cybersecurity workspace for anyone starting in security, practicing CTFs, working in GRC, or researching defensive techniques.\n\n## What is inside\n\n- **Command center** for quick-start actions, learning pulse, recommended tools, and saved work\n- **Explore** library with curated open-source tools across offensive security, blue team, GRC, research, and analysis\n- **Learn** tracks for foundations, CTF, web security, blue team, GRC, and research\n- **Workspace** for saved tools, field notes, and personal checklists\n- **Tool briefs** with purpose, use cases, safe-start guidance, and source links\n\nAll personal state is stored locally in the browser for this first release. The UI repeatedly reinforces a simple rule: only test systems you own or are explicitly authorized to assess.\n\n## Run locally\n\nRequires Node.js and pnpm.\n\n    pnpm install\n    pnpm run dev\n\nThe Vite config defaults to port 5173 and can be customized with PORT and BASE_PATH.\n\n## License\n\nMIT\n
